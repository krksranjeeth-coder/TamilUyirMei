# தமிழ் உயிர்மெய் பயிலரங்கம் • TamilUyirMei
### Animated Tamil Uyir-Mei Learning Lab for Kids

An interactive, animated educational web application designed for Tamil school children and diaspora learners worldwide to master the 216 **Uyir-Mei (உயிர்மெய்)** letters with visual shape families, stroke-by-stroke writing guides, finger/mouse tracing canvas, child-friendly English explanations, pause-and-learn video, and animated GIF exports.

---

## 🌟 Key Features

1. **Child-Friendly Visual Formulas (6 Easy Shape Families)**:
   - Dynamic visual equation: `[ க் ] + [ ஆ ] ➜ [ கா ]`
   - Explains how consonants (18 letters with dots) and vowels (12 sound friends) join hands:
     - **Family 'a' (அ)**: புள்ளி மறைதல் (Dot vanishes like a butterfly)
     - **Side-Leg Family (ஆ)**: துணைக்கால் (ா - Side-leg stands on the right)
     - **Roof-Hook Family (இ, ஈ)**: மேல்விலங்கு (ி / ீ - Cute roof hook curls over head)
     - **Bottom-Curl Family (உ, ஊ)**: கீழ் வளைவு (ு / ூ - Special bottom loops & hooks)
     - **Front-Horn Family (எ, ஏ, ஐ)**: முன் கொம்பு (ெ / ே / ை - Horn stands guard before the letter)
     - **Surround Family (ஒ, ஓ, ஔ)**: சாண்ட்விச் சூத்திரம் (Sandwich hug — horns hold the letter from both sides)

2. **Step-by-Step Writing Guide (Stroke Order)**:
   - Breakdown of writing sequence with easy English explanations (e.g. for கெ: 1. `ெ` Front horn, 2. `க` Consonant; for கொ: 1. `ெ`, 2. `க`, 3. `ா`).
   - Explains writing positions: முன்னால் (Front), மேலே (Above), பின்னால் (After), கீழே (Bottom), இருபுறமும் (Surrounding).

3. **Practice Pad (எழுதிப் பழகுங்கள் • Trace & Write)**:
   - Four-line / two-line ruled Tamil notebook guidelines.
   - Ghost letter guide for tracing.
   - Child-friendly palette (Ruby, Marigold, Emerald, Azure, Purple).
   - Undo, clear, and celebratory stars/confetti when kids finish writing.

4. **Multi-Format Export & Learning Materials**:
   - **🎬 MP4 Video (Pause & Learn)**: Step-by-step video lessons kids can pause, scrub, and replay.
   - **🖼️ 4-Step Learning Card (PNG)**: Visual infographic showing Consonant ➔ Vowel Rule ➔ Stroke Order ➔ Word & Sentence.
   - **🎥 Animated GIF (450x450)**: High-quality animated mini-lesson for any of the 216 combinations.
   - **📁 12-Letter Mei Series ZIP**: Downloads all 12 combinations for a consonant in an organized folder.
   - **📦 Complete 216 Letters ZIP**: Complete offline archive organized into 18 consonant folders.
   - **📇 Flashcard PNG**: High-resolution printable flashcards for offline practice.

5. **216-Letter Matrix & 12 Rules Cheat Sheet**:
   - Interactive 18 Mei x 12 Uyir table. Click any cell to jump to it instantly.
   - Quick reference of all 12 vowel formulas with bilingual kid rules.

6. **Interactive Quiz Mini-Game**:
   - Generates random combinations (`த் + இ = ?`) with 4 colorful choices.
   - Confetti particle bursts, star counter, and visual praise.

7. **100% Quiet & Child-Friendly**:
   - Completely free of startling sounds or bleeps — clean visual focus for classroom and quiet home study.

## 🚀 How to Run

### Method 1: Double-Click Launcher (macOS)
Simply double-click `start.command` in the project directory. It launches a local server and opens `http://localhost:3333/index.html` in your browser.

### Method 2: Direct File Open
Open `index.html` directly in Google Chrome or any modern browser:
```bash
open index.html
```

### Method 3: Local Web Server
```bash
python3 -m http.server 3333
```
and open `http://localhost:3333/index.html`.
